# Основные команды Git

## 1. Что такое Git?

**Git** — это система контроля версий, которая позволяет отслеживать изменения в файлах, сохранять историю проекта и работать над ним совместно с другими разработчиками.

**GitHub** — это онлайн-платформа для хранения Git-репозиториев и совместной работы над проектами.

## 2. Основные команды Git

### `git init`

**Для чего используется:** создаёт новый локальный Git-репозиторий в текущей папке.

**Как используется:**

```bash
git init
```

Команда создаёт скрытую папку `.git`, в которой хранится история изменений проекта.

### `git add`

**Для чего используется:** добавляет новые или изменённые файлы в область подготовки к коммиту (staging area).

**Как используется:**

```bash
git add README.md
```

Чтобы добавить все изменения:

```bash
git add .
```

После выполнения команды выбранные файлы будут подготовлены к сохранению в истории Git.

### `git commit`

**Для чего используется:** сохраняет подготовленные изменения в истории репозитория.

**Как используется:**

```bash
git commit -m "Добавлен README"
```

Параметр `-m` позволяет указать краткое описание изменений.

### `git push`

**Для чего используется:** отправляет локальные коммиты в удалённый репозиторий, например на GitHub.

**Как используется:**

```bash
git push origin main
```

Здесь `origin` — имя удалённого репозитория, а `main` — название ветки.

### `git pull`

**Для чего используется:** получает изменения из удалённого репозитория и объединяет их с текущей локальной веткой.

**Как используется:**

```bash
git pull origin main
```

Команду используют, чтобы обновить локальный проект изменениями, опубликованными на GitHub.

### `git branch`

**Для чего используется:** показывает существующие ветки или создаёт новую ветку.

**Как используется:**

Посмотреть список веток:

```bash
git branch
```

Создать новую ветку:

```bash
git branch feature
```

Переключиться на неё:

```bash
git switch feature
```

Создать ветку и сразу переключиться на неё:

```bash
git switch -c feature
```

Ветки позволяют разрабатывать новые функции отдельно от основной версии проекта.

### `git merge`

**Для чего используется:** объединяет изменения из одной ветки с текущей веткой.

**Как используется:**

```bash
git switch main
git merge feature
```

В этом примере изменения из ветки `feature` объединяются с веткой `main`. Если Git обнаружит конфликт изменений, его необходимо разрешить вручную.

### `git clone`

**Для чего используется:** создаёт локальную копию удалённого репозитория.

**Как используется:**

```bash
git clone https://github.com/username/repository.git
```

Вместо `username` указывается имя пользователя GitHub, а вместо `repository` — название репозитория.

## 3. Дополнительные полезные команды

### `git status`

Показывает состояние файлов: какие изменения сделаны, какие файлы подготовлены к коммиту и какие ещё не отслеживаются.

```bash
git status
```

### `git log`

Показывает историю коммитов.

```bash
git log
```

Для краткого списка коммитов:

```bash
git log --oneline
```

### `git remote`

Позволяет просматривать и настраивать удалённые репозитории.

```bash
git remote -v
```

Добавить удалённый репозиторий:

```bash
git remote add origin https://github.com/username/repository.git
```

## 4. Пример последовательности работы

Ниже приведён пример создания проекта и отправки его на GitHub:

```bash
git init
git add .
git commit -m "Первый коммит"
git branch -M main
git remote add origin https://github.com/username/repository.git
git push -u origin main
```

Перед выполнением последней команды необходимо создать пустой репозиторий на GitHub и заменить ссылку на адрес своего репозитория.

## 5. Pull Request

**Pull Request (PR)** — это запрос на включение изменений из одной ветки в другую. Он позволяет проверить изменения перед объединением с основной веткой.

Пример работы:

1. Создать новую ветку:

   ```bash
   git switch -c feature
   ```

2. Изменить файлы и сохранить изменения:

   ```bash
   git add .
   git commit -m "Обновлена документация"
   ```

3. Отправить ветку на GitHub:

   ```bash
   git push -u origin feature
   ```

4. На GitHub создать Pull Request из `feature` в `main`.
5. Проверить изменения и выполнить Merge Pull Request.

## Заключение

Git помогает отслеживать историю проекта, сохранять изменения и работать с несколькими версиями файлов. GitHub позволяет публиковать репозитории в интернете и совместно разрабатывать проекты. Основные команды `init`, `add`, `commit`, `push`, `pull`, `branch`, `merge` и `clone` являются базовыми инструментами для работы с Git.
